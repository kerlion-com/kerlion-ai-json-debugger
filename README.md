# KERLION AI JSON Debugger

Debug, inspect, and validate JSON generated by AI models — directly in your browser.

KERLION AI JSON Debugger is a focused browser-based developer tool for diagnosing structured responses from AI assistants and language models. It covers the workflow after an AI response has been generated: extracting JSON from surrounding prose, identifying syntax problems, validating a result against JSON Schema, and checking multiple samples for structural consistency.

## Features

- Paste complete AI responses, including explanatory prose and Markdown code fences.
- Extract a JSON object or array from surrounding response text.
- Parse JSON and report parser details, including line and column when exposed by the browser.
- Inspect formatted output, copy it, or download it as a JSON file.
- Validate the parsed value against a JSON Schema.
- Test multiple JSON samples against the same schema.
- Arabic and English interface with RTL support.
- Dark and light themes.
- Client-side processing of pasted response content.

## Run locally

No build step is required.

1. Clone or download this repository.
2. Open `index.html` in a modern browser.
3. Paste an AI response and select **Analyze output**.
4. Add a JSON Schema to validate the expected structure.
5. Add sample responses to run a batch check against the same schema.

A local static server is recommended:

```bash
npx serve .
```

The JSON Schema validator is loaded from a pinned Ajv CDN build. Schema validation requires access to that CDN unless you self-host the dependency.

## Technology

- HTML5, CSS3, and Vanilla JavaScript
- [Ajv 8](https://ajv.js.org/) for JSON Schema validation

## Validation scope and limitations

- JSON Schema validation uses Ajv 8. The exact supported schema dialect depends on the bundled Ajv build.
- Parser line and column details depend on the browser's native JSON parser error message.
- Extraction from prose is heuristic. Ambiguous or malformed nested content may need manual correction.
- Batch checks compare each sample to the supplied schema. They do not measure semantic similarity.
- A passing schema check does not prove that values are factually correct, safe, authorized, or suitable for production. Applications must still enforce their own validation and business rules.
- This project does not connect to an AI model and does not generate or repair model responses.

## Privacy

Pasted response text and schema are processed in the browser and are not sent to a KERLION backend. The Ajv validator is loaded from the configured CDN. For fully offline or restricted environments, self-host the dependency and remove the CDN dependency from `index.html`.
